对象默认呆在"它在的地方"；仅当需被单独寻址 / 被整体引用时才对象化（reify）——边、谓词、标签三个起点，同一条定律

reify 通用定律

对象默认呆在节点的位置或边的位置（或谓词/标签的位置），仅当需要被单独寻址、被作为整体引用时才对象化（reify）成可命中节点。 触发 = "查询需求决定本体"。

能独立提问？
用户会单独问"X 是什么/放哪层" → 升节点
需挂属性？
如时态、来源、可信度要有地方放 → 升节点
需被图遍历/命中？
作检索路由入口 → 升节点

三个起点：命题从【边】升、维度/可比面从【谓词】升、术语从【标签】升——同一模式，三个起点。

概念 concept

稳定实体，canonical 名；结构层 subClassOf / partOf / involves / precedes；聚合同名命题。

文档 document

信息内容实体，rdf:type=document；带元数据；只走 cites / partOf / asserts，不进语义层。

术语 term

denotes 概念，带时态与来源；默认是标签（skos:altLabel），需挂时态/来源或作入口时才升实体；同义用 sameAs。

命题 = 三元组（边）

非实体。主体—谓词—客体一条有向边；仅在需被引用审计/作论证端点/挂出处时 reify 成 proposition 节点。

三层结构（谓词 vs 边 vs 标签）

概念：harness（canonical）
结构层：harness ⊇ linter / 结构测试 / 仓库知识 / CI 闸门 / 评审自动化 partOf
harness → blast radius 前置 precedes
标签（命名）：rdfs:label "harness" ／ skos:altLabel "scaffolding"（早期）→ 需时态/来源时升 term 实体 term
概念：containment（canonical）
谓词（维度）：concept 防线层级置于 取值
维度必然是谓词；"被几个概念引用"是自然事实（本例仅 containment 用），不是建模分档。唯一分界 = 是否 reify 成轴实体节点（独立提问/挂属性/被遍历时）
边（谓词的一次实例化）：(containment) —防线层级置于→ (组织层) source=O2　；　(containment) —防线层级置于→ (环境层) source=A5
reify 示例（边 → 命题节点）
S1 = "containment 防线层级置于 组织层"（source O2）　S2 = "containment 防线层级置于 环境层"（source A5）
→ S1 complement S2（维度已并入谓词，无需再标）；S2 support ← "爆炸半径随能力扩张而增长"（也 reify）
文档：O2 / A5（document 实体） 只走 cites / partOf / asserts，不在互补/分歧里

命题 reify 四触发

① 加 provenance　② 加时态/可信度/主张主体　③ 作 support/attack 端点　④ 被引用审计

三个自研增量

① 检索路由入口：哪些概念/命题提升为可命中入口
② 维度/可比面组织：facet 作比较轴排布——多方对照难点是"在哪个轴上可比"，先命中轴再沿轴取各源立场（cmp-002：防线层级轴 → 组织层/环境层）
③ 出处链与引用锚对接：声明→容器片段 ↔ 判官引用锚（连续块组），三粒度对齐

v0.5 修正：① 维度 = 谓词（OWL 里即 object/data property，同一物）；"私有/共享"只是被几个概念引用的自然事实，不是建模分档；
② "升级为独立轴"唯一分界 = 是否 reify（独立提问/挂属性/被遍历时）成轴实体节点；未 reify 就只是谓词，无"对象属性 vs 轴节点"两档；
③ 谓词/边/标签三层：类型定义 / 一次实例化 / 命名——都不是图两端对象，默认非节点；
④ reify 通用定律：默认位置 → 三判据（独立提问/挂属性/可命中）触发对象化；
⑤ 语义不重复标注：维度并入谓词后边不重复标。含：前驱边实例、共享型轴命名节点未出现——属切片范围非缺类。
