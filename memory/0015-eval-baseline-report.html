重要发现 1：多工具并行调用 400（真 bug）

combined-002（分别计算两个乘积）与 combined-007（同时问日期和除法）报错：An assistant message with 'tool_calls' must be followed by tool messages responding to each 'tool_call_id'。

根因：模型一次响应里返回了多个并行 tool_calls，而 loop 只执行第一个（tool_events[0]）、只回填一条 tool 消息。API 协议要求每个 tool_call_id 都有对应的 tool 消息。

修复方向：每轮执行全部工具调用，逐条回填 tool 消息（一个 assistant tool_calls + N 条 tool 结果）。

意义：这是评测体系第一次抓到代码 bug——正是“跑批验证”的价值。

重要发现 2：机器判定覆盖面偏窄

70 条用例中只有 13 条带 tool_used criterion；stream_complete 与 latency_budget 没有任何用例使用（judged=0）。建议后续给 tool_call / combined 用例补充这两个 criteria，提高自动化判定覆盖率——它们都是机器可判的。
