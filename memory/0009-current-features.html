当前主要功能（阶段 1，2026-08-26）

  • 前后端分离架构：Vue 3 + TS 前端 / Python + FastAPI 后端 / SSE 流式对话
  • 对话能力：多轮上下文 + 流式输出（打字机效果）+ 会话模式（通用 / 知识库优先 / 工具增强）
  • LLM 配置：前端设置面板配置 DeepSeek API Key 与模型（deepseek-chat / deepseek-reasoner）；Key 脱敏存取、SQLite 持久化
  • 手写 Agent Loop：思考→行动→观察循环，支持多轮工具调用（上限 4 轮）与 tool_calls 回显（含并行调用合并回显）；输出护栏 PromptLeakGuard（增量检测系统提示泄露，命中即截断替换，chat 与评测共用）；行为契约 BASE_BEHAVIOR（歧义/指代不明/信息不足/自相矛盾时澄清或覆盖说明，结合对话上下文判断）；歧义词表附加说明（高频歧义词如"整除/左右"命中时追加独立消息提示模型，不改用户原话）
  • 内置工具：安全计算器（AST 求值 + 精确性语义：Fraction 有理数精确运算、有限小数/循环小数区分显示、sqrt/完全幂判定、结果自带精确/近似声明；描述明确不支持时间字符串）/ 日期时间（current_datetime 纯获取：时区 zoneinfo、星期几、中文时段标注；datetime_shift 相对推算：显式 base + delta，基准为入参而非调用时刻）/ 笔记（保存——description 覆盖"记/提醒/待办"映射 / 按标题读取 / 空标题列出全部 / note_search 模糊检索）；注册表 + 执行器架构
  • 存储抽象：Port + Adapter 结构；设置持久化 SQLite，会话/日志暂用内存实现
  • 测试：81 个用例全绿（冒烟、设置接口、LLM 客户端 Mock、Agent loop、输出护栏、上下文组装、内置工具、eval schema/runner/评测台、统计聚合）
  • 处理过程可视化：SSE trace 事件 + 前端“处理过程”面板（事件流 + 语义摘要 + 原始流开关 + 每轮 token 用量与汇总）
  • 评测体系：golden set 用例 schema + 首批 70 条用例 + 最小评测 runner（重试/并发控制）+ 真实基线 68/70（多工具并行 400 bug 已修复）+ Excel 人工标注表
  • 评测台（P1，0017）：用例管理 Web UI（CRUD / 筛选 / 备注拆分 notes+admin_note / 启停）+ 测试管理 UI（后台跑批、进度、结果跟踪、汇总对比、取消）+ 人工标注 UI 化（替代 Excel 为主途径）+ JSON 导出；用例仍以 JSON 文件为真源，跑批结果入 SQLite
  • 评测台（P1.5，2026-08-24）：独立页面（hash 路由、新标签打开）+ 跑批详情独立页（输入输出逐条展开 / 全部展开 / 人工标注）+ 历史跑批自动刷新 + 历史跑批删除（运行中拒绝）；标注结论可沉淀回用例（annotation 金标准字段），为后续自动判定做数据基础；运行指南补充沙箱出网注意事项
  • 评测强化（2026-08-25）：LLM-as-judge（金标准优先 / 预期行为兜底 + 判定理由 + 工具调用上下文 + uncertain 转人工，判官复用生成 LLM）；repeat 稳定性采样（1–10 次串行，聚合 pass/unstable/fail/exec_error/pending，UI 显示通过 X/N 徽章与逐 try 详情）；金标准批量生成器（按预期行为起草、注入反幻觉口径，70/70 全量生成）；运行管理增强（逐用例重跑覆盖原结果并清标注/失效核验、核验标记 verify/unverify）；SQLite 连接泄漏修复；评测台 UI 设计系统（共享样式 eval-ui.css + 弹窗编辑 + 字段说明 + 判定参考展示 + unstable 筛选）
  • 评测驱动修复（2026-08-26）：judge 校准（reason 引用原文、uncertain 收紧防过度转人工、数值类"核对不重算"、pending 必带 reason、JSON 未转义引号容错解析）；工具化提示词（工具可覆盖的确定性任务必须调用工具 + 一次调用不拆步骤）；工具能力补齐（计算器精确语义、datetime 时区/星期/delta、note 列出与检索）；trace 落盘（exec_trace 有序执行轨迹 + 前端"执行轨迹"查看，失败可回放）；tool_used 判定支持"任一预期工具"；金标准对齐系列修复（inject-005 维度、fuzzy-004 矛盾口径、inject-003 单轮分支、refuse-004 替代方法边界、combined-007 精确值、tool-calc-009/016/017 整除/精确/术语、fuzzy-005 商歧义、note-get 系列检索预期）；新增用例 fuzzy-005、tool-calc-016/017；tool_used 批量补齐
