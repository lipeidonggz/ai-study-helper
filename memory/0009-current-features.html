用途

从本记录开始，每次 git 提交的说明中必须包含“当前项目主要功能”摘要，随项目演进更新。本记录是该清单的权威副本，功能有增删时同步维护，并在 commit message 中保持一致。

当前主要功能（阶段 1，2026-08-24）

  • 前后端分离架构：Vue 3 + TS 前端 / Python + FastAPI 后端 / SSE 流式对话
  • 对话能力：多轮上下文 + 流式输出（打字机效果）+ 会话模式（通用 / 知识库优先 / 工具增强）
  • LLM 配置：前端设置面板配置 DeepSeek API Key 与模型（deepseek-chat / deepseek-reasoner）；Key 脱敏存取、SQLite 持久化
  • 手写 Agent Loop：思考→行动→观察循环，支持多轮工具调用（上限 4 轮）与 tool_calls 回显（含并行调用合并回显）
  • 内置工具：安全计算器（AST 求值）/ 日期时间 / 笔记保存 / 笔记读取；注册表 + 执行器架构
  • 存储抽象：Port + Adapter 结构；设置持久化 SQLite，会话/日志暂用内存实现
  • 测试：26 个用例全绿（冒烟、设置接口、LLM 客户端 Mock、Agent loop、eval schema/runner）
  • 处理过程可视化：SSE trace 事件 + 前端“处理过程”面板（事件流 + 语义摘要 + 原始流开关 + 每轮 token 用量与汇总）
  • 评测体系：golden set 用例 schema + 首批 70 条用例 + 最小评测 runner（重试/并发控制）+ 真实基线 68/70（多工具并行 400 bug 已修复）+ Excel 人工标注表
  • 文档：记忆库 0001–0016（需求 / 验收 / 架构 / 里程碑 / 进度 / 代码导读 / 最小 Agent 全貌）+ 运行指南 docs/how-to-run.html
  • 代码注释：backend 全部 Python 文件中文注释（文件头职责与设计原因、流程逐行说明）

提交规范（以后所有提交都遵守）

  1. commit 说明分为两部分：标题（本次改动一句话）+ 正文（当前项目主要功能摘要）
  2. 功能摘要直接从本记录复制并同步最新状态；功能有变化时先更新本记录
  3. 敏感信息（API Key、密钥）绝不允许出现在 commit 或记录中
