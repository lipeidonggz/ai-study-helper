原则与维护

  • id = 稳定身份，永不改（避免断开 eval_run_cases 历史关联与考古引用）；
  • tag 只作分组/筛选元数据，判官与跑批不解析 tag——改键名 = 对 18 个 JSON + 本表 + UI 轴配置做字符串替换，成本低、不影响历史；
  • 新取值必须先在本表登记；同一用例可多套件/多验证标注（如 cmp-002 既是基准也兼检索验证）。
