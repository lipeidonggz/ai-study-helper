主线叙事（先记住这条链路）

用户在界面发消息 → 前端 send() 调 /api/chat → 后端端点检查 API Key（无 Key 返回 error 事件）→ 进入 Agent loop（思考→行动→观察循环）→ 循环内流式调用 DeepSeek → 边生成边通过 SSE 推回前端 → 前端解析 SSE 事件实时渲染。若模型决定调用工具，loop 执行工具并把结果回填上下文，再进入下一轮（上限 4 轮）。

第一遍：跟随一次对话请求（推荐顺序）

  1. backend/app/main.py + backend/app/di.py（约 2 分钟）

    应用入口与依赖组装：create_app() 建 FastAPI 实例、注册路由；AppDeps 把存储等依赖装进 app.state。看重点：依赖从哪来、路由挂在哪。

  2. backend/app/api/chat.py（约 5 分钟）

    对话端点：校验请求 → _build_llm() 从设置取 Key 构建客户端（无 Key 发 error 事件）→ 返回 StreamingResponse。gen() 是 SSE 生成器，逐个事件 yield，异常透传给前端。

  3. backend/app/agent/loop.py（约 10 分钟，全场重点）

    run_agent_turn() 是手写 Agent 循环：流式调用 LLM → 收到 tool_call 事件就执行工具、结果回填消息列表 → 再来一轮。看明白这个文件，Agent 核心机制就通了。

  4. backend/app/agent/context.py（约 3 分钟）

    assemble()：系统提示（按会话模式选择）+ 历史 + 当前消息。当前是雏形；阶段 2 的上下文预算、检索注入都在这里长出来。

  5. backend/app/agent/llm.py（约 10 分钟）

    DeepSeekLLMClient：chat()（非流式，测试用）与 stream()（真实流式）。重点看 stream() 如何解析 SSE、如何把零散的 tool_calls 片段拼成完整调用、以及 tool_calls 回显（LLMMessage.tool_calls）为什么必要。FakeLLMClient 是占位，先不看。

  6. backend/app/tools/ 三个文件（约 5 分钟）

    顺序：builtin.py（工具长什么样：名字/描述/参数 schema/handler）→ registry.py（注册表，schemas() 把工具转成 API 认识的格式）→ executor.py（执行入口，阶段 4 的沙箱加在这里）。

  7. backend/app/api/settings.py（约 2 分钟）

    Key 的存取与脱敏，很短，扫一眼即可。

  8. backend/app/storage/（约 5 分钟）

    ports.py（接口定义）+ sqlite/settings_store.py（SQLite 实现）是 Port/Adapter 结构；现在只用到 SettingStore，其余接口为后续阶段预留。

  9. 最后读测试（约 5 分钟，反证理解）

    tests/test_llm_client.py（Mock 传输层，展示客户端协议）、tests/test_settings.py（接口行为）、tests/test_smoke.py（SSE 事件流）。测试即“应该表现为什么样”的规格。

第二遍：架构视角

  • 依赖方向：前端 → API 契约层 → Agent 核心 →（知识库/工具/存储）。Agent 核心不直接碰数据库，通过存储接口访问。
  • 接口先行：ports.py 里 DocumentStore / VectorStore / Embedder 尚未实现，是阶段 2/3 的落点；换实现不换接口。
  • 依赖注入：main.create_app 里 build_deps() 一次性组装，测试里替换成内存实现即可隔离数据库。
  • 范围控制三处落地：配置存于存储层（LLMSettings/GlobalSettings）、执行在 Agent 核心（模式路由）、展示在前端（设置面板）。

验证理解的方法

  • 浏览器发一条消息，Network 面板看 /api/chat 的 SSE 事件，对应 gen() 里每个 yield。
  • 在 loop.py 的循环里临时加 print(messages)，看每轮上下文怎么变，看完删掉。
  • 自问自答：为什么 stream() 要收集 raw_tool_calls 并回显？答不上来就回读 llm.py 与 loop.py。
